## Implementation atoms

1. Range validation, double authority, coherent snapshots, clamping/snapping
   and no-op model publication. Equal endpoints are inert; finite spans and
   representable positive steps are required; ties go upward and the maximum
   remains reachable. Logical intervals are independent of native tick density.
2. Keyed selection snapshots with deep option copies, availability/selection
   validation and the existing index compatibility methods. Duplicate titles
   remain valid; duplicate/empty keys do not. No setter synthesizes USER input.
3. Per-channel existing callback registrations, immutable queued events,
   reserved terminal credits and lossless relative adjustments. Preserve
   interaction/revision/sequence identity and guard exhaustion.
4. Actual native tracking/action/menu notifications, with typed SDK projection
   and scoped foreign registrations. Capture immutable state synchronously,
   defer application delivery, and retain failures through recordNativeFailure.
5. Model replacement, native interruption and eligibility loss retire tracking
   exactly once. Never restore over newer model state, admit a delayed terminal
   from an abandoned interaction, or invoke a cancel receiver during owner close.
